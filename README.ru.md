# equeue-bot — монитор электронной очереди (pasport.org.ua)

Скрипт открывает страницу электронной очереди в настоящем браузере (headful,
через Playwright), периодически перезагружает её, выбирает нужную услугу в
выпадающем списке и проверяет, есть ли свободные места. Пока висит надпись
«Вибачте, на даний момент всі місця зайняті!» — молчит. Как только она пропадает
(значит, места появились) — печатает в консоль и шлёт уведомление в Telegram.

Скрипт **ничего не бронирует** — только следит и уведомляет.

## Как это работает (цикл проверки)

Каждый цикл (`check()` в `equeue_probe.py`):

1. **Полная перезагрузка** страницы (`page.goto`, реальный новый запрос).
2. Проверка, что страница вообще загрузилась (маркер «електронна черга»), а не
   Cloudflare / «забагато запитів».
3. **Заново выбирается услуга в дропдауне** (`<select>`) — по подстроке текста,
   по умолчанию `Закордонний паспорт та (або) ID-картка`.
4. Пауза ~2 сек, чтобы страница подгрузила доступность для выбранной услуги.
5. Ищется текст «всі місця зайняті»:
   - есть → статус **зайнято**;
   - нет → статус **вільно** → уведомление в Telegram.
6. Сон ~60 сек (с джиттером ±10 → **50–70 сек**, чтобы запросы не были
   одинаковыми) и снова к шагу 1.

То есть да: **на каждом цикле страница перезагружается и дропдаун выбирается
заново** — состояние `<select>` после reload не сохраняется, поэтому выбираем
каждый раз.

## Что нужно поставить

Требуется Python 3.10+ и один пакет — `playwright` (см. `requirements.txt`),
плюс браузер Chromium для Playwright.

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m playwright install chromium
```

### Windows

```bat
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m playwright install chromium
```

## Как запустить

### macOS / Linux

```bash
.venv/bin/python -u equeue_probe.py
```

### Windows

Проще всего через `run.bat` (он сам берёт `.venv`, пишет вывод в `run.log` и
пробрасывает доп. аргументы):

```bat
run.bat
run.bat --poll 90
```

## Настройка Telegram (.env)

Без `.env` скрипт просто печатает статус в консоль. Чтобы приходили уведомления,
создай файл `.env` рядом со скриптом (шаблон — в `.env.example`):

```
BOT_TOKEN=<токен от @BotFather>
CHAT_ID=<твой chat id>
```

`CHAT_ID` можно узнать так: написать боту любое сообщение, затем открыть
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` и взять `chat.id`.

## Аргументы командной строки

| Аргумент            | По умолчанию                              | Описание |
|---------------------|-------------------------------------------|----------|
| `--url`             | prague.pasport.org.ua/solutions/e-queue   | Адрес страницы очереди |
| `--service`         | `Закордонний паспорт та (або) ID-картка`  | Текст пункта дропдауна (поиск по подстроке) |
| `--poll`            | `60`                                      | Базовый интервал между проверками, сек |
| `--jitter`          | `10`                                      | Случайный разброс ± к интервалу (→ 50–70 сек) |
| `--cooldown`        | `600`                                     | Пауза после «забагато запитів» (too many requests), сек |
| `--heartbeat-hours` | `4`                                       | Раз в сколько часов слать «я жив» (0 = выключить) |

Примеры:

```bash
# другая услуга
.venv/bin/python -u equeue_probe.py --service "ID-картка"

# проверять реже (каждые ~90 сек)
.venv/bin/python -u equeue_probe.py --poll 90 --jitter 15
```

## Заметки

- Первый запуск может показать окно Cloudflare / очереди — если так, пройди его
  вручную один раз, профиль браузера сохраняется в `.equeue_profile`.
- Не ставь слишком маленький `--poll`: сайт ограничивает частые запросы страницей
  «забагато запитів», после чего скрипт ждёт `--cooldown` секунд.
